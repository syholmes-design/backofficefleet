Privacy

A plain-language view of the data this website uses.

The BOF public site is primarily static. Some demonstration and portal simulations store state in the visitor's browser, and the public contact path opens the visitor's email application. This page describes current observed site behavior and should receive legal review before being treated as a final policy.

Ask a privacy question →

Static public pages

The public site is delivered as HTML, CSS, JavaScript, images, audio, video, and static data files on shared hosting.

Local browser state

Selected customer-portal simulations use localStorage and a restricted investor-plan surface uses sessionStorage on the visitor's device.

Email contact

Mailto links send information through the visitor's email provider and BOF's email service, outside the static website itself.

Current site behavior

Use only the information needed for the interaction.

The local site code reviewed for this notice does not contain a site-wide advertising tracker. Hosting providers may still create standard server logs, and external email providers process messages according to their own practices.

  1. 01

    Browsing the site

    The host may process standard request information such as IP address, browser details, requested path, date, and time for delivery and security.

  2. 02

    Using simulations

    Some static portal or access simulations store state locally in the browser so the experience can remember a choice or staged record.

  3. 03

    Sending email

    Information placed in an email is processed by the sender's provider, the recipient's provider, and the people handling the inquiry.

  4. 04

    Requesting help

    A visitor may email BOF with a privacy or accessibility question without sending sensitive fleet or personal records.

Qualification

Privacy boundaries

This website should not be used as a secure document-upload channel.

  • Do not send driver medical, license, tax, banking, insurance, customer, credential, or claim records through an unsolicited public email.
  • Static demo records are intended to be synthetic and are not presented as live customer records.
  • Browser storage can normally be cleared through browser settings; doing so may reset local simulation state.
  • This notice documents observed current behavior and is not a substitute for review by qualified privacy counsel.
