# Demo Completeness Audit Skill

Use this skill before demos and after changes to visible BackOfficeFleet routes.

## Checks
- Every visible button, link, tab, modal, dropdown, card, and table has useful behavior or useful content.
- No visible "TODO", "placeholder", "coming soon", generic fake fields, or unexplained empty states remain.
- Demo data uses trucking-specific labels such as drivers, loads, assets, settlements, PODs, BOLs, route proof, credentials, and compliance actions.
- Owner-facing report lists page, issue, impact, recommended fix, priority, and owner decision needed.

## Completion Standard
A demo user can click through the route without hitting a dead end or obviously unfinished surface.
