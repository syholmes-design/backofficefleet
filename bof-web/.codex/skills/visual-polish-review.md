# Visual Polish Review Skill

Use this skill when reviewing BackOfficeFleet presentation quality across marketing, BOF internal pages, and portals.

## Checks
- Spacing, hierarchy, typography, contrast, alignment, and button/card consistency.
- Mobile and desktop layout sanity.
- No huge blank areas, horizontal overflow, clipped controls, or incoherent overlaps.
- Any global CSS change is validated visually on representative routes.

## Completion Standard
The page looks intentional, data-rich, and demo-ready without requiring a broad redesign.
