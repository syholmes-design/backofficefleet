# Before Demo Checklist

1. Run environment smoke checks from `docs/codex-environment-runbook.md`.
2. Start the dev server.
3. Run `npm run audit:demo-clickability`.
4. Run `npm run audit:bof-links`.
5. Run `npm run audit:demo-completeness`.
6. Run `npm run audit:visual-smoke`.
7. Run document-focused validations relevant to the demo path.
8. Write a plain-English readiness summary in `.codex/reports/demo-completion-report.md`.
