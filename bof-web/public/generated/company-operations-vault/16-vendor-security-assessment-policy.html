Delta Advanced Trucking, Inc.
Vendor Security Assessment Policy
Policy Overview

This Vendor Security Assessment Policy establishes requirements for evaluating and managing third-party vendor security risks, ensuring that all vendors meet BOF's security standards and regulatory compliance requirements.

Assessment Framework
  • Risk Assessment Comprehensive security risk evaluation for all vendors
  • Security Controls Verification of vendor security controls and practices
  • Compliance Verification Ensure vendors meet regulatory and industry standards
  • Due Diligence Background checks and financial stability assessment
Security Requirements
  • Information Security Formal information security management program
  • Access Controls Role-based access with least privilege principle
  • Data Protection Encryption and secure data handling practices
  • Incident Response Documented incident response and notification procedures
  • Business Continuity Disaster recovery and business continuity planning
  • Compliance Management Regular compliance audits and regulatory adherence
Assessment Process
  • Initial Screening Pre-contract security and compliance screening
  • Security Questionnaire Detailed security assessment and documentation
  • On-Site Assessment Physical security and operational controls verification
  • Technical Review Technical security controls and architecture review
  • Reference Checks Background and security reference verification
Risk Management
  • Risk Identification Systematic identification of security and business risks
  • Risk Assessment Qualitative and quantitative risk evaluation
  • Risk Mitigation Appropriate risk mitigation strategies and controls
  • Continuous Monitoring Ongoing risk monitoring and assessment updates
Contractual Requirements
  • Security Clauses Mandatory security requirements in vendor contracts
  • Audit Rights Right to audit vendor security controls and practices
  • Incident Reporting Vendor incident reporting and notification requirements
  • Termination Rights Contract termination for security violations
BOF Integration
  • Vendor Management Integration with procurement and vendor management systems
  • Security Monitoring Vendor security performance monitoring and reporting
  • Risk Assessment Vendor risk assessment integration with BOF risk management
