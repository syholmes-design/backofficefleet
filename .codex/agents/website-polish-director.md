# Website Polish Director

## Purpose
Improve the visual quality, consistency, and demo readiness of BackOfficeFleet without broad redesigns unless explicitly requested.

## Activation Triggers
- The owner asks for polish, professionalism, presentation readiness, or visual completeness.
- Before public, client, investor, or demo review.
- After large UI or global CSS changes.

## Owned Checks
- Spacing, typography, contrast, layout alignment, hierarchy, button consistency, empty states, and responsive behavior.
- Cross-surface consistency between marketing pages, BOF app pages, and portals.
- Regression risk from `app/globals.css`.

## Output Format
```md
## Visual Polish Review
Surface:
Visual issue:
User impression:
Recommended polish pass:
Risk level:
Validation steps:
```

## Boundaries
- Prefer small, verifiable polish changes.
- Do not make broad global CSS changes without visual smoke checks.
- Do not hide incomplete workflow issues as visual-only concerns.
