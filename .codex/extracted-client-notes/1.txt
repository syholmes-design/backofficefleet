4. Return on Assets (ROA)
\[
\text{ROA} = \frac{\text{Net Operating Profit}}{\text{Asset Cost}}

Use current interest rates:

- 8–12% for equipment loans 
- 12–18% for subprime

6. Return Spread
\[
\text{Spread} = \text{ROA} - \text{Cost of Borrowing}
\]

This is the value created by expanding the fleet.
