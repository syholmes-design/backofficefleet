Date: 2026-06-07

- BOF remains the product; AscendTMS remains the source-system context for the simulated load workflow.

When future client instructions mention API, sync, adapters, services, credentials, TypeScript, React, Next.js, backend routes, or database behavior, translate the visible business intent into a static simulated demo surface unless the user explicitly asks for real integration work.
