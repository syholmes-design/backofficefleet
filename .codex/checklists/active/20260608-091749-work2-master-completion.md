## Operating Rules

- Work one item at a time and update status/evidence before moving on.
- Use `pending`, `in_progress`, `complete`, `blocked`, `deferred`, or `not_applicable`.
- Do not mark an item `complete` without current evidence.
- Use `deferred` only when the item is real but intentionally out of current scope.
- Use `blocked` only when external input, client authorization, source access, or user direction is required.
- Keep `Website` as the active edit target.
- Do not edit `bof-web-Original`; use it only as reference.
- Do not add React, Next.js, TypeScript, npm packages, `.env`, credentials, backend routes, database, auth, uploads, or live API/sync.
- Any AscendTMS/TMS work remains simulated unless the user explicitly changes the boundary.
