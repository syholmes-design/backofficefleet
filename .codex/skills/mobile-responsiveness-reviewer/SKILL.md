# Mobile Responsiveness Reviewer

Use this skill whenever phone or tablet usability is important.

## Purpose

Make the new BOF website/demo usable and clear on mobile devices.

## When To Use

- Sidebar behavior
- Cards
- Tables
- Forms
- Touch targets
- Mobile navigation
- Responsive spacing
- Tablet layout

## Procedure

1. Identify the mobile viewport and the key task.
2. Review navigation, hierarchy, tap targets, overflow, and scroll length.
3. Convert dense desktop patterns into mobile-first summaries or cards.
4. Prioritize the demo path on small screens.
5. Recommend acceptance checks for phone and tablet.

## Checks

- No accidental horizontal overflow.
- Text is readable.
- Buttons are tappable.
- Navigation is not overwhelming.
- Dense content is summarized or hidden.
- The demo still makes sense on mobile.

## Output Format

```markdown
## Mobile Responsiveness Review

Surface:
Mobile risk:
Recommended layout:
Touch/navigation notes:
Acceptance criteria:
```

## Safety Boundaries

- Do not treat mobile as a copy of desktop.
- Do not add extra mobile-only complexity unless it improves clarity.
