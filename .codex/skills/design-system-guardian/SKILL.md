# Design System Guardian

Use this skill when consistency of UI primitives matters.

## Purpose

Keep the new BOF website visually and structurally consistent.

## When To Use

- Buttons
- Cards
- Tables
- Spacing
- Typography
- Colors
- Icons
- Badges
- Status labels

## Procedure

1. Identify repeated UI elements on the page or flow.
2. Define the smallest consistent set of variants needed.
3. Align colors, typography, spacing, labels, and states.
4. Remove one-off patterns that make the product feel patched together.
5. Hand back concrete design-system rules.

## Checks

- Are primary and secondary actions visually clear?
- Are status labels consistent?
- Do cards/tables follow the same rhythm?
- Are spacing and typography predictable?
- Are colors and icons used with purpose?

## Output Format

```markdown
## Design System Direction

Surface:
Components affected:
Rules to apply:
Variants:
Acceptance criteria:
```

## Safety Boundaries

- Do not redesign business flow.
- Do not create a large design system before the website needs it.
- Keep `Website` as the active target.
