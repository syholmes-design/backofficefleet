# Light Self-Contained Product Shell Idea

Status: pinned for later, not the current direction.

## Idea

The current `/interactive-demo/` experiment explored a self-contained BOF program shell:

- No public website header, nav, CTA band, or footer once the buyer enters Try Demo.
- A simulated access screen and 5-8 second loading/session handoff.
- A light enterprise operations UI rather than dark mode.
- A shell with sidebar rail, topbar, load queue, selected record drawer, document pane, release controls, and in-app record viewer.
- Clicks stay inside the program by updating in-app records, documents, packets, notes, and statuses instead of linking back to public website pages.

## Why Keep It

This may work as an alternative walkthrough or controlled product-shell demo concept later. It is useful if BOF needs a self-contained app simulation that feels separate from the marketing website and keeps buyers inside one controlled environment.

## Why It Is Paused

The visual look was not yet the desired direction. Future work should revisit the idea from the product-shell architecture level rather than polishing the current visual pass.

## Future Revisit Prompt

Revisit the pinned light self-contained product shell idea for BOF and redesign the visual language from scratch while preserving the core concept: no website chrome, simulated access/loading flow, self-contained in-app records, and a credible operations program shell.
