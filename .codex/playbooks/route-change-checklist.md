# Route Change Checklist

1. Confirm active route ownership in `docs/BOF_ROUTE_MAP.md`.
2. Identify the primary component and data source.
3. Avoid legacy aliases and generated artifacts unless explicitly in scope.
4. Run the route-specific demo completeness audit.
5. Run route link/artifact checks.
6. Capture a visual smoke screenshot on desktop and mobile when UI changed.
7. Summarize impact in owner-friendly language.
