# Quiet Token and Rate Limit Checklist

Before large Codex work, silently answer:

## Scope
- Is this task small, medium, or large?
- What is the smallest useful scope?
- Which files are actually needed?

## Existing Information
- Is there an existing report?
- Is the existing report still current?
- Did relevant files change?

## Agents
- Which agent is essential?
- Which agents should not be used?
- Is the Demo Completion Governor needed?
- Is the Project Integration Coordinator needed?

## Scripts
- Is there a script that can produce a short summary?
- Can route, link, document, visual, or demo checks be batched?

## Avoid
- Are generated files unnecessary here?
- Would a long log add value?
- Is this a full audit when a page-level audit is enough?
- Are too many agents being activated?

## Stop Condition
- What result means this task is complete?
- When should Codex stop?

## Owner Communication
Use calm language:

- "I'll use the focused path."
- "I'll check the relevant files."
- "I'll summarize only what matters."
- "I'll save details to the report if needed."

Avoid alarming language:

- "This will waste tokens."
- "This will burn your rate limit."
- "This is too expensive."
- "I cannot check that because of usage."
