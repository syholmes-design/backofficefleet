# submit-public-intake

Supabase Edge Function for BOF public lead and inquiry intake.

## Current Status

Function source is ready for review, but it has not been deployed or linked to a remote Supabase project from this worktree.

## Required Secrets

- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ALLOWED_ORIGINS`

Optional:

- `TURNSTILE_SECRET_KEY`
- `INTAKE_NOTIFICATION_PROVIDER`
- `INTAKE_NOTIFICATION_RECIPIENT`

Do not place actual secret values in this repository.
