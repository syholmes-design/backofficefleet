# Assessment Conversion Strategy

## Conversion Principle

The visitor receives value before BOF asks for follow-up. The flow is:

1. Understand the assessment value.
2. Choose the closest operating profile.
3. Answer 12 practical questions.
4. Review answers.
5. See a preliminary readiness result.
6. Optionally request a detailed roadmap, readiness review, or Priority Fleet consideration.

## Visitor-Facing Value

The assessment now communicates:

- Identify your highest-risk operating gaps.
- See which BOF workflows apply.
- Receive a prioritized readiness roadmap.
- 12 questions.
- Approximately 4 minutes.
- No obligation.

The hero no longer emphasizes browser mechanics, deep links, or internal architecture language.

## Result Conversion

Each result includes:

- readiness band
- overall readiness indicator
- strongest area
- top three operational gaps
- section-level summary
- recommended BOF modules/workflows
- detailed-roadmap CTA
- assessment-specific next step
- disclaimer

Private Fleet, For-Hire Fleet, and Aggregator results may also show Priority Fleet consideration. The language says the operation may be a candidate and does not claim qualification.

## Non-Persistent Form State

The detailed-roadmap action is interaction-ready but does not submit data. The note says:

`Detailed roadmap requests are handled through a BOF readiness review. This page does not transmit personal data.`

No fake success state is shown.

## Measurement Points For Future Work

If a secure backend workflow is approved later, track:

- selected audience
- completion rate
- drop-off question index
- result band
- selected conversion action
- readiness review requests

Do not add tracking, storage, or submission without approved privacy and backend handling.
