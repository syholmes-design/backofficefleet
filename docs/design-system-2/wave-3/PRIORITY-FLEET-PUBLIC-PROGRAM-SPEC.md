# Priority Fleet Public Program Spec

## Public Route

`/priority-fleet-program/`

The route is public, indexable, canonical, and included in the sitemap.

## Page Purpose

Explain BOF's Priority Fleet Program to qualified fleet operators and invite assessment-led consideration requests.

## Primary Audience

- Private Fleets
- For-Hire Fleets

Secondary consideration:

- select Aggregators
- select public-fleet pilots

## Public Positioning

Hero eyebrow:

`Priority Fleet Program`

Hero headline:

`Help shape the operating system your fleet actually needs.`

Primary CTA:

`Apply for Priority Fleet Consideration`

Secondary CTA:

`Start the Fleet Readiness Assessment`

## Qualification Statement

`Participation is subject to operational fit, implementation readiness, and BOF approval.`

## Benefit Language

Approved benefit areas:

- prioritized operational assessment
- tailored integration planning
- early access to selected BOF workflows as they fit the implementation plan
- direct implementation collaboration
- opportunity to influence product direction through practical operating feedback
- structured readiness roadmap

## Promise Boundaries

The page must not promise acceptance, financial outcomes, regulatory outcomes, special commercial terms, ownership interest, or specific contract terms.

## Visibility Added

- Homepage Priority Fleet strip now links to `/priority-fleet-program/`.
- `/who-we-serve/` includes a lower Priority Fleet section.
- `/private-fleets/` includes a lower Priority Fleet banner.
- `/for-hire-fleets/` includes a lower Priority Fleet banner.
- Assessment result logic includes Priority Fleet consideration only for Aggregator, Private Fleet, and For-Hire Fleet.

## Future Enhancements

If secure submission is approved later, create a real application workflow with privacy copy, validation, consent, backend handling, and owner review.
