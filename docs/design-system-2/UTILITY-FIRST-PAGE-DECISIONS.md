# Utility-First Page Decisions

- `/load-readiness/`: rebuilt around a pre-trip readiness packet.
- `/network-readiness/`: added a carrier and operating-unit readiness roster.
- `/fleet-preparedness/`: added a public fleet preparedness board.

## Existing Utility Pages Retained

- `/documents/`: already leads with document intake, classification, review, expiration, access, and audit controls.
- `/bof-vault/`: already leads with document requests, uploads, renewals, access, and audit state.
- `/policies-procedures/`: already leads with controlled policy library, versions, acknowledgments, training, exceptions, and audit evidence.
- `/business-operations/`: existing approved public hero was retained; utility content continues through workspace and operating-area controls.

## Control Rule

New utility controls are either local buttons with visible panel updates or real links to related operating pages. No new dead `#` controls were introduced.
