# BOF Logo Specification

Status: Wave 0 owner-review asset package.

## Owner Direction Captured

The DS2 logo package follows the latest owner direction:

- Use a three-road symbol to the left.
- Keep the first road dark navy.
- Keep the center road navy with white lane markings.
- Make the third road brown to represent off-road trucking.
- Angle the BOF initials to communicate motion.
- Preserve the existing white opening/path concept and carry it horizontally through the BOF initials.
- Use the lower BackOfficeFleet wordmark direction from the newer reference.
- Do not use bevels, gradients, glows, 3D effects, or shadows in production logo assets.

## Usage Guidance

Use the primary horizontal logo on light backgrounds when horizontal space is available.

Use the reversed logo on dark navy header, footer, and portal surfaces.

Use the compact or mobile-header logo in constrained navigation.

Use symbol-only only for favicon, app icon, compact mark, or social avatar contexts.

## Production Note

This package is an isolated DS2 foundation package. It does not replace the current production logo files. Before final brand adoption, the owner should approve the exact geometry of the horizontal path, road proportions, and wordmark spacing.
