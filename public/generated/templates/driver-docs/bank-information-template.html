Security and Privacy

Security Notice:

  • Bank information is kept confidential and used only for payment processing
  • Account details are stored securely in encrypted systems
  • Information is shared only with authorized payroll and banking personnel
  • Drivers may request changes to banking information at any time
  • All changes require written verification and re-authorization

Change Instructions

How to Update Banking Information:

  1. Complete new bank information form
  2. Provide voided check or bank letter for new account verification
  3. Submit to payroll department with proper identification
  4. Allow 5-7 business days for changes to take effect
  5. Monitor for test deposits to verify new account
