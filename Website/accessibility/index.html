Accessibility

BackOfficeFleet aims to make its public website usable, readable, keyboard-friendly, and understandable. This draft does not claim formal accessibility certification.

Feedback path

Report access issues through Contact.

Include the page URL, device or browser, and a short description of the issue so BOF can review it.

Last updated: July 28, 2026

Commitment

BOF works to keep the public website accessible through semantic HTML, readable copy, keyboard-operable controls, visible focus states, responsive layouts, and meaningful link text.

Current Measures

The public site includes labeled navigation, descriptive page titles, alt text for meaningful imagery, visible form labels, status messaging for local form validation, and responsive layouts across desktop and mobile viewports.

Known Draft Status

This is a launch draft. Some older demo experiences and retained media may require additional transcript, caption, keyboard, and assistive-technology review before being treated as production-ready.

Feedback

Use the Contact page to report an accessibility issue. Please include the page, the action you were trying to complete, and the assistive technology or browser involved if relevant.

No Certification Claim

This page is an accessibility statement draft and does not claim WCAG certification, legal compliance certification, or third-party audit approval.
