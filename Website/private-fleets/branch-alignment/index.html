Branch lens

Which local rule applies, who owns the hold, and what clears the move?

Branch alignment does not flatten operations. It makes each local exception visible in the same language.

Yard

Local constraints

Branch alignment route

  1. Map: capture each yard, branch, route type, service rule, and document expectation.
  2. Normalize: translate local differences into shared readiness states.
  3. Route: assign exceptions to branch, dispatch, safety, billing, or document owners.
  4. Measure: show recurring blockers by branch so leaders can fix the pattern.
