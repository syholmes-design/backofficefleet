# BOF Design System 2.0 Brand Assets

Generated foundation assets for owner review. SVG files are the editable source of truth; transparent PNG exports are provided at 1x, 2x, and 3x. Existing production logo files were not overwritten.

The logo direction preserves the owner-requested three-road mark, brown third road path, forward-leaning BOF initials, and a horizontal white path carried through the original BOF opening.
